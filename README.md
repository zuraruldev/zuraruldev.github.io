# Arul / Zura - Portfolio

A simple, elegant portfolio website built with HTML, CSS, and JavaScript. This is a CV-based personal website showcasing skills, education, experience, and blog entries.

## Features

- **Dark/Light Theme Toggle** - Switch between dark and light modes with persistent storage
- **Programming Languages Showcase** - Displays expertise in C++, JavaScript, and Python with relevant frameworks
- **Interactive Teto Button** - Click to play an animated gif and mp3 music file
- **Smooth Animations** - Beautiful fade-in, slide, and rotate animations throughout
- **Responsive Design** - Works seamlessly on desktop and mobile devices
- **Blog Section** - Link to annual reviews spanning 2024-2028
- **Social Links** - Quick access to email, GitHub, and Discord

## Technologies Used

- HTML5
- CSS3 (with animations and CSS variables)
- Vanilla JavaScript
- Font Awesome Icons
- Google Fonts (Lora)

## Local Development

1. Clone the repository:
```bash
git clone https://github.com/zuraruldev/zuraruldev.github.io.git
cd zuraruldev.github.io
```

2. Open `index.html` in your browser or use a local server:
```bash
python -m http.server 8000
# Then visit http://localhost:8000
```

## Features Breakdown

### Programming Languages
- **C++** - Systems programming, algorithms, and competitive programming
- **JavaScript** - Full-stack web development with React.js, Next.js, and Node.js
- **Python** - Machine learning and data science with TensorFlow, PyTorch, and scikit-learn

### Interactive Elements
- Click the "Click me" button to display an animated gif with background music
- Toggle between system, light, and dark themes
- Hover effects on profile, buttons, and items

### Animations
- Staggered fade-in animations for sidebar elements
- Smooth slide animations for the Teto gif
- Rotation and scale effects on logo images
- Pop-in animation for the Click me button
