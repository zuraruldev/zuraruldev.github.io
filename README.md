# Manarul Hidayat - Portfolio

A simple, portfolio website built with HTML, CSS, and JavaScript. This is a CV-based personal website showcasing skills, education, experience, repos, awards, blogs.

## Local Development

1. Clone the repository:
```bash
git clone https://github.com/zuraruldev/zuraruldev.github.io.git
cd zuraruldev.github.io
```

2. Open `index.html` in your browser or use a local server:
```bash
python -m http.server 8000
# Then visit http://localhost:8000
```

## Deployment

This site is deployed on GitHub Pages at: **https://zuraruldev.github.io**
